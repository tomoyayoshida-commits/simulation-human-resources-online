# 能力バー（貢献度の内訳を1本のバーで見せる）— 実装計画

作業机（#p4 / #p5）のカードに、4能力値のバーを出す。バーの全長＝能力値、濃い部分＝その事業部の
重みぶん＝寄与。**濃い部分の長さを足すと貢献度になる**という関係を、式を読ませずに見せる。

モック：`mockup-ability-display.html`（案③）。

## 1. 確定事実（再調査不要）

改修前に実物を確認した結果：

- 生の4能力値が画面に出るのは**取込プレビューの先頭5名だけ**（`importPanel.ts` の `.slice(0, 5)`）。
- 作業机のカードに出るのは 社員ID／氏名／型／貢献度（現所属＋他事業部）のみ。
  能力値も人件費も出ない（`workbenchPanel.ts` `buildCardHtml` / `hiringWorkbenchPanel.ts` `buildCardHtml`）。
- 4能力値が揃うのは CSV 出力（`csv.ts` `buildEmployeeCsv`）＝画面外。
- 型（`calcEngine.classifyType`）は「4能力値のうち最大に対応する型」。同点は 営業→管理→開拓→育成
  で潰れるため、能力の要約としては粗い。実例：営業88/管理52 と 営業71/管理69 はどちらも「営業型」で、
  A事業部での貢献度は 63.90 と 62.30（営業力の差17に対し貢献度の差は1.60）。
- 重みの合計は A/B/C とも 1.00（`constants.WEIGHTS`）。よって
  `Σ(能力値 × 重み) = 貢献度` は「バー全長100に対する濃い部分の合計」と一致する。
  **この一致が案③の根拠**で、重みが 1.00 に正規化されている限り常に成り立つ。
- 重みは `SimParams.weights` でオプション画面から変更できる（`paramsOptions.ts`）。
  したがってバーの濃淡は `DEFAULT_PARAMS` ではなく **`state.params.weights[unit]` を使う**。
  ここを定数から読むと、重みを変えたときに「濃い部分の合計＝貢献度」が崩れる。

## 2. 候補比較と決定

| 案 | 内容 | 判定 |
|---|---|---|
| 案1 | 貢献度の内訳を式で表示（クリックで展開） | 不採用。クリックしないと存在に気づかれない |
| 案2 | 能力バー4本（濃淡なし） | 不採用。貢献度との関係を説明せず、別の「なぜ？」を生む |
| **案3** | **能力バー＋寄与の濃淡** | **採用**。能力値と貢献度の関係が1枚で閉じる |
| 案4 | 案1+案3 併用 | 見送り（案3で足りるか本番で確認してから判断する） |
| 案5 | 取込プレビューの5名制限を外す | 別件として保留。作業机とは独立に効く |

## 3. 設計

### 3.1 描画の形

```
営 ▓▓▓▓▓▓▓▒▒▒▒▒▒▒▒▒▒░░░░░░░░░  88
   └── 濃い(重み .45 ぶん) ┘
   └────── 全長 = 能力値 88 ──────┘
```

- 外側トラック幅 100% が能力値 100 に対応。
- `fill` の幅 = `能力値%`。
- `fill` の中の濃い部分の幅 = `重み × 100%`（fill に対する割合）。
  → 濃い部分の絶対長 = `能力値 × 重み` = その能力の寄与。
- 濃い部分の色は事業部色（`UNIT_VAR`）。薄い部分は同色の淡色。

### 3.2 所属のない候補（#p5 のプール列）

重みが決まらないので**濃淡を付けない**（中立色のバーのみ）。
プール列のカードは元から3事業部ぶんの貢献度を横並びで出しており、そこは変えない。

### 3.3 表示のON/OFF

`顔写真` と同じ作法でチェックボックスを1つ足す（#p4 `wb-show-abilities`／#p5 `hwb-show-abilities`）。
**既定はON**。理由は顔写真と同じで、既定OFFだと機能に気づかれないまま終わるため。
カード1枚が高くなり列に同時に見える枚数が減るので、俯瞰したいときはOFFで従来の密度へ戻せる。

## 5. 受入基準

1. 既定（`showAbilities` 未指定）で、#p4 / #p5 のカードに4本のバーが出る。
2. `fill` の幅が能力値と一致する（例：営業力88 → `width:88%`）。
3. 濃い部分の幅が `state.params.weights[unit]` と一致する（例：A・営業 → `width:45%`）。
   **オプションで重みを変えたら濃淡もその値で描かれる**（`DEFAULT_PARAMS` を見ない）。
4. #p5 のプール列（所属なし）のカードには濃淡が付かない。
5. `showAbilities: false` でバーが1本も出ず、HTML が従来と同じ高さに戻る。
6. 貢献度・売上・利益・最適化結果は1ビットも変わらない（計算ファイルに触れない）。
7. 社員番号・氏名のエスケープは従来どおり（`escapeHtml`/`escapeAttr`）。
