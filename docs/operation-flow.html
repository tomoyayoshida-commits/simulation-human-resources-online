操作フロー — 人材配置シミュレーター（Movez）

画面は5つ（トップ／配置案の検討／採用判断／人材登録／保存した配置案）。
「配置案の検討」と「採用判断」は同じ形で、データ取込 → 比較 → 作業机 の3ステップを進み、作業机の保存から出力画面へ合流します。

主動線（進む） 戻る（「← 前の画面へ戻る」・パンくず） 別ルート（トップからの直行・トップバー） 縦線付きの囲み＝進めない条件（分岐のゲート）

起動

認証状態を復元中（スピナーのみ表示）

ログイン画面

Googleでログイン／許可外・失敗はここに留まりエラー表示

トップ#p0

  • 入口2つ＋「保存した配置案を見る・出力する」
  • ログアウト

配置案の検討：データ取込#p4-import

  • 社員データCSVをドラッグ&ドロップ／ファイル選択 → 100名の検証
  • 詳細（先頭5名プレビュー）・入力検証レポート・配置の前提条件
  • 計算オプション（前提パラメータ編集／標準に戻す）
  • ファイルを変更／取り込みを解除（＝未取込に戻す）
エラー1件でもあると「配置方針を比較する」ボタンごと消える → 該当行を直して再取込
◀ トップ「前回の続き」はここへ着地

4課題横断比較#p4-result

  • 4課題（全社売上／A利益／B売上／C売上）× 最適化「売上・利益」＝8通り
  • 表示切替：利益で見る／売上で見る
  • カード下「この配置案を選ぶ」＝選択だけ（実行不能なカードには出ない）
1つ選ぶまで下部の「調整する」は押せない
◀ トップ「作りかけの配置を開く」はここへ着地

作業机（100名）#p4-bench

  • ドラッグ&ドロップで異動（カードを選んで列をクリックでも可）
  • 🔒 個人ロック／並び順（社員番号・貢献度・型別・人件費）／顔写真ON・OFF
  • 元に戻す・リセット（出発点＝選んだ最適解へ）
  • この人数配分のまま最適に組み直す（固定した社員がいると押せない）
  • 一時保存／一時保存を開く（このブラウザだけ）
  • この案を保存 → 名前を付けて確定保存（同名は拒否）
制約違反があっても保存はできる。止まるのは出力側

採用判断：データ取込#p5-import

  • 左＝採用前100名／右＝追加採用10名の2ファイル
  • 採用の前提条件（適正人数は100名基準で据え置き）・オプション
左が先（右だけ先に入れると保留）／既存と社員番号が重複する候補は保留
分岐：左CSVに「配置先事業部」列あり → 現行配置が出発点（既存100名は既定で固定）／ 無ければ 採用前の最適解が出発点（固定は既定で解除）
◀ トップ「前回の続き」はここへ着地

採用前後比較#p5-result

  • 目的（4課題 × 売上・利益＝8通り）を選ぶ
  • 選び直すと採用前・採用後の両方を解き直す
  • 採用ROI（追加人件費コスト／売上増分／利益増分）
◀ トップ「作りかけの採用案を開く」はここへ着地

作業机（A/B/C＋採用候補プール）#p5-bench

  • 4列目「採用候補」に残した候補は採用しない（＝見送り）
  • 「既存100名を固定する」チェック（現行配置が出発点なら既定ON）
  • 既存社員は採用候補列に入れられない（理由を表示）
  • 元に戻す／リセット／組み直し／一時保存／この案を保存（#p4 と同じ）
採用前100名で制約を満たす配置が無いと作業机を開けない

保存した配置案 → 出力#p7（一覧 → 出力の2ステップ）

  • 一覧：名前・種別（配置100名／採用判断100＋N名）・課題・全社売上・全社利益・調整名数・状態・保存日時・保存者 → 名前をクリックで出力へ
  • 出力3種：データCSV（100名ちょうどの案は取り込み直して再計算できる）／告知用PDF（社員番号・氏名・配属先）／エグゼクティブサマリPDF（数字と根拠のみ・個人名なし）
  • PDFはブラウザの印刷ダイアログから「PDFに保存」
制約違反の案は3つとも押せない（何がどれだけ足りないかを表示）→ 作業机で直して保存し直す。 保存済みの案は追記のみ・書き換え不可

入口：トップバー「保存配置」／トップ下部のボタン／作業机で保存した直後（自動でここへ）

トップバー（全画面共通）

  • ロゴ＝トップへ／「人材登録」＝#p6／「保存配置」＝#p7
  • パンくずで手前のステップへ直接戻れる

人材登録#p6

  • ① 名簿CSV（社員番号,氏名,写真ファイル名／写真列は省略可）
  • ② 顔写真をまとめて投入（128pxへ自動縮小・1枚10MBまで）
  • 突合の警告（写真が無い・名簿に無い等）は出るが保存は止めない
  • 「マスタに保存する」→ 登録済み一覧に反映
  • 一覧で ✎ 氏名・写真の差し替え／✕ 削除／チェックして一括削除

入口：トップバー／#p4・#p5 の比較画面・作業机にある「人材登録」ボタン。 登録内容は次に作業机を開いたときにカードへ出る

リロードしたとき

  • 取込データ・前提パラメータ・到達点は復元されるが、画面はトップに戻る（勝手に前回位置へ飛ばさない）
  • 作業机の手動編集は復元対象外 → 復元は比較結果まで
  • #p7 にいた場合は一覧まで戻して読み直す
  • トップの「前回の続き」「作りかけを開く」は、戻せるものがあるときだけ出る

「一時保存」と「この案を保存」の違い

  • 一時保存＝作りかけの盤面をこのブラウザに置くだけ。タブを閉じても残り、#p4 と #p5 で別々。他の人には見えない
  • この案を保存＝サーバへ1件追記。全員が #p7 で見られ、保存者と日時が残る。更新・削除はできない
  • 一時保存を開くと「元に戻す」の履歴は引き継がれない

↳ 前回の続き取込済みで、かつ前回比較まで進んでいたときだけ表示。計算し直して比較結果へ
↳ 作りかけの配置／採用案を開く一時保存があるときだけ表示。比較を経由せず作業机へ直行

#p4 4課題横断比較 カードの「最適化：売上／利益」そのカードだけ指標を切り替えて解き直す（4課題×2＝8通り）
この配置案を選ぶ選択されるだけで画面は動かない。実行不能なカードには出ない
選んだ配置案の人員配置を調整する ▶選んだカードの配置を出発点に作業机を開く。未選択だと押せない
#p4／#p5 作業机 カードをドラッグ&ドロップその社員を移す。全社売上・充足率・Δがその場で更新。違反時は「次にできること」を表示
🔒（カード内）その社員を動かせなくする
この人数配分のまま最適に組み直す人数配分を保ったまま割当だけ解き直す。固定した社員がいると押せない（全員を置き直すため）
元に戻す／リセット直前の1手を取り消す／出発点の配置へ戻す
一時保存／一時保存を開く盤面をこのブラウザに置く／戻す。下書きが無いときは「開く」が押せない
この案を保存名前を入力 → 保存。同名があると拒否。成功すると #p7 の出力画面へ直行（制約違反でも保存はできる）
#p5 データ取込 採用前100名を投入「配置先事業部」列があれば現行配置が出発点（既存100名は既定で固定）。無ければ採用前の最適解が出発点
追加10名を投入左が未取込だと保留。既存の社員番号と重複しても保留
採用前後比較を見る ▶選んだ目的で採用前・採用後を解いて比較画面へ
#p5 採用前後比較 目的（8通り）を選び直す採用前・採用後の両方を解き直して並べ替える。ROI表も更新
#p7 保存した配置案 一覧から1件を開く出力画面へ。保存直後だけ3つの出力の違いを説明する案内が出る
CSV／告知用PDF／サマリPDF制約違反の案は3つとも押せない。不足の内訳を表示し、作業机で直して保存し直す運用
#p6 人材登録 名簿CSV＋顔写真 → マスタに保存する突合の警告があっても保存できる（計算には影響しないため）。反映は次に作業机を開いたとき

この図の読み方（設計上の決めごと）

  • 入口は必ず利用者が選ぶ。リロード後も前回位置へ自動で飛ばさず、トップで「始める（取込から）」「前回の続き」「作りかけを開く」を選ばせる。
  • 選択と実行を分ける。比較画面のカードは選ぶだけ、画面が動くのは下部の実行ボタンだけ。
  • 止めるのは出力のときだけ。制約違反でも記録としては保存でき、CSV・PDFの出力で止める。
  • 保存した配置案は追記のみ。直したい場合は作業机で直して別名で保存し直す。
